# BubbleShop

WhatsApp Business Sales Agent backend built with ASP.NET Core 10 Web API and Clean Architecture.

## Prerequisites
- .NET SDK 10
- SQL Server
- Docker & Docker Compose (optional)

## Solution layout
- `src/BubbleShop.Domain`
- `src/BubbleShop.Application`
- `src/BubbleShop.Infrastructure`
- `src/BubbleShop.API`
- `tests/*`
